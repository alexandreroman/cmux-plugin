# Project Memory

> When a new decision **contradicts** an existing
> memory note, do NOT silently override it.
> Instead: surface the conflict, quote the
> existing memory, explain how the new decision
> differs, and ask for explicit confirmation
> before updating. **Do NOT take any action** —
> no tool calls, no file writes — until confirmed.

- [Skill doc writing style](references/feedback_skill-doc-writing-style.md) — write cmux skill docs in present tense, no version refs or comparative wording
- [Evaluating new cmux releases](references/feedback_evaluating-cmux-releases.md) — assess if a new cmux version needs plugin changes (usually no)
